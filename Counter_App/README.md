## Counter App

```
Create a simple Counter App using HTML, CSS, and JavaScript.
```

### Requirements:

* Create a number display starting from 0.
* Add three buttons:
    * ```+``` Increase
    * ```-``` Decrease
    * Reset
* When the user clicks  ```+```, increase the number by 1.
* When the user clicks ```-```, decrease the number by 1.
* When the user clicks Reset, set the number back to 0.
* Use CSS to make the counter visually appealing and center it on the page.

### Style Requirements:

* Center the counter app both horizontally and vertically on the page.
* Use a card-style container with a clean background, rounded corners, and a subtle shadow.
* Make the counter number large and bold so it is easy to see.
* Place the three buttons in a single horizontal row with proper spacing.
* Give each button a clear and attractive background color.
* Use rounded corners and remove the default button appearance.
* Add a hover effect so the buttons visually change when the mouse moves over them.
* Add a smooth transition to make the hover effect look natural.
* Make the  ```+``` and ```-``` buttons visually distinct from the Reset button.
* Add sufficient padding and spacing around the elements so the interface does not look crowded.
* Use a simple, modern font family and a light page background.
* Ensure the layout remains usable on smaller screen sizes.

### Concepts covered:

* HTML buttons and elements
* CSS styling and centering
* ```querySelector()```
* ```addEventListener()```
* Variables
* Updating textContent
* Basic ```if``` conditions
