## Simple To-Do List
```
Create a To-Do List using HTML, CSS, and JavaScript.
```
### Requirements:

* Create an input field where the user can type a task.
* Create an Add Task button.
* When the user clicks Add Task:
* Get the value from the input.
* Add the task to a list below.
* Clear the input field.
* Each task should have a Delete button.
* Clicking Delete should remove that particular task.
* If the input is empty, display a message such as "Please enter a task."
* Use CSS to make the task list clean and readable.

### Example:
```
[ Buy Milk             ] [Add Task]

☐ Buy Milk              [Delete]
☐ Learn JavaScript      [Delete]
☐ Complete Assignment   [Delete]
```
### Concepts covered:

* HTML forms/input
* CSS layout and styling
* ```querySelector()```
* ```createElement()```
* ```appendChild()```
* ```addEventListener()```
* ```.value```
* ```.textContent```
* ```if/else```
* DOM manipulation
